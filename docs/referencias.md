# Referências

As ferramentas abaixo são mantidas pelos respectivos autores. Consulte a documentação e a licença da versão escolhida antes de usar ou redistribuir. Elas não são dependências da biblioteca.

- [sp_WhoIsActive](https://github.com/amachanic/sp_whoisactive): análise de sessões e atividade.
- [First Responder Kit](https://github.com/BrentOzarULTD/SQL-Server-First-Responder-Kit): diagnóstico e análise de SQL Server.
- [Ola Hallengren SQL Server Maintenance Solution](https://ola.hallengren.com/): manutenção, backups e integridade.
- [SQLskills](https://www.sqlskills.com/): artigos e scripts dos autores.
- [Glenn Berry — Diagnostic Queries](https://glennsqlperformance.com/resources/): consultas de diagnóstico por versão.
- [Microsoft Learn — T-SQL](https://learn.microsoft.com/en-us/sql/t-sql/language-reference): referência da linguagem.

Os links nos cabeçalhos dos scripts indicam a documentação dos catálogos, funções e DMVs usados. Não copiar capturas de resultados reais para exemplos ou documentação pública.
