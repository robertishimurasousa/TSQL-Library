# References

The following tools are maintained by their respective authors. Review the documentation and license for the version you choose before using or redistributing it. They are not dependencies of this library.

- [sp_WhoIsActive](https://github.com/amachanic/sp_whoisactive): session and activity analysis.
- [First Responder Kit](https://github.com/BrentOzarULTD/SQL-Server-First-Responder-Kit): SQL Server diagnostics and analysis.
- [Ola Hallengren SQL Server Maintenance Solution](https://ola.hallengren.com/): maintenance, backups and integrity checks.
- [SQLskills](https://www.sqlskills.com/): articles and scripts from the authors.
- [Glenn Berry — Diagnostic Queries](https://glennsqlperformance.com/resources/): official author resources. An attributed, version-pinned selection from the requested mirror is bundled in this library; see the [collection guide](glenn-berry/README.md) and [separate terms](../THIRD_PARTY_NOTICES.md).
- [Microsoft Learn — T-SQL](https://learn.microsoft.com/en-us/sql/t-sql/language-reference): language reference.

Script headers link to documentation for the catalogs, functions and DMVs they use. Do not copy actual query results into public examples or documentation.
